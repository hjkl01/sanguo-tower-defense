# 三国烽火 · Sanguo Tower Defense

基于 Unity 的三国题材塔防游戏。玩家通过抽卡收集大量武将，在固定防守点位部署武将，并在战斗中手动切换阵容。

## 核心设计

- **武将池不设 12 人上限**：武将以数据配置为主，新增武将不需要新增战斗代码。初始数据集将覆盖魏、蜀、吴、群雄多个阵营，后续持续扩充。
- **抽卡收集**：单抽、十连抽；抽卡结果进入永久武将收藏。
- **固定点位布阵**：每个防守点位部署一名武将；战斗中可以手动换将。
- **武将养成**：武将等级与武将副本相互独立，合成规则通过参数控制。
- **单机优先**：第一阶段采用本地存档，不依赖服务器。

## 武将合成规则（第一阶段）

每个武将拥有唯一的 heroId，同一武将的多份抽卡结果以独立副本记录。合成时选择一个目标副本，以及若干个**同武将、同等级**的材料副本。默认消耗 2 个材料副本，目标副本提升 1 级；材料数量可配置。不能把目标副本本身当材料，不能跨武将、跨等级合成，也不能超过等级上限。

## 技术结构

- Assets/Scripts/Data：武将静态配置
- Assets/Scripts/Domain：武将副本与收藏
- Assets/Scripts/Services：抽卡、合成、布阵

## 开发路线

1. 基础领域系统：数据驱动武将模型、收藏副本、抽卡、同等级合成、固定点位布阵。
2. 战斗原型：敌人沿路径移动、波次管理、自动攻击、技能和胜负结算。
3. Unity 场景与 UI：主菜单、武将收藏、抽卡、养成、布阵、战斗界面。
4. 本地存档、数值平衡、音效和美术资源。
