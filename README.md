# 三国烽火 · Sanguo Tower Defense

基于 Unity 的三国题材塔防游戏。玩家通过抽卡收集大量武将，在固定防守点位部署武将，并在战斗中手动切换阵容。

## 核心设计

- **武将池不设 12 人上限**：已加入 50 名魏、蜀、吴、群雄武将的原型数据。新增武将只需扩展 JSON 配置，不需要新增战斗代码。
- **抽卡收集**：单抽、十连抽；抽卡结果进入永久武将收藏。
- **固定点位布阵**：每个防守点位部署一名武将；战斗中可以手动换将。
- **武将养成**：武将等级与武将副本相互独立，合成规则通过参数控制。
- **单机优先**：第一阶段采用本地存档，不依赖服务器。

## 武将合成规则（第一阶段）

每个武将拥有唯一的 heroId，同一武将的多份抽卡结果以独立副本记录。合成时选择一个目标副本，以及若干个**同武将、同等级**的材料副本。默认消耗 2 个材料副本，目标副本提升 1 级；材料数量可配置。不能把目标副本本身当材料，不能跨武将、跨等级合成，也不能超过等级上限。

## 技术结构

- Assets/Scripts/Data：武将静态配置
- Assets/Scripts/Domain：武将副本与收藏
- Assets/Scripts/Services：抽卡、合成、布阵

## 开发路线

1. 基础领域系统：数据驱动武将模型、收藏副本、抽卡、同等级合成、固定点位布阵。
2. 战斗原型：敌人沿路径移动、波次管理、自动攻击、技能和胜负结算。
3. Unity 场景与 UI：主菜单、武将收藏、抽卡、养成、布阵、战斗界面。
4. 本地存档、数值平衡、音效和美术资源。

## 当前阶段

仓库已补齐 Unity 项目基础结构，包括 Packages 清单、Unity 版本、主场景、运行时启动脚本、50 名武将数据和设计文档。主场景会从 JSON 读取武将目录并生成基础原型 UI，可试用抽卡、选中武将、合成和固定点位部署。

### 本地运行

1. 安装 Unity Hub，并安装 Unity 2022.3 LTS（项目版本见 ProjectSettings/ProjectVersion.txt）。
2. 克隆仓库，在 Unity Hub 中选择 **Add project from disk**，指向仓库根目录。
3. 等待 Unity 导入资源和编译脚本。
4. 打开 Assets/Scenes/Main.unity，点击 Play。
5. 如果需要把武将数据变成可在 Inspector 中编辑的资源，执行菜单 **Sanguo → Import Hero Catalog**。

当前已实现：固定路径敌人行军、按"最接近基地"优先的自动索敌、5 波次战斗、击杀与通关金币奖励、暂停/继续、本地 JSON 存档（版本迁移 + 原子写入，启动时自动恢复）。数值集中在 `BattleTuning` 中统一配置。正式美术、音效与更深的养成线仍在后续开发范围。GitHub 提交尚未在本环境中通过 Unity Editor 实际构建验证。

建议使用 Unity 2022.3 LTS 或更新的 LTS 版本。
