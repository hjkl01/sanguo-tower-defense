# 三国烽火 · Sanguo Tower Defense

《三国烽火》是一款基于 Unity 开发的三国题材单机塔防游戏。玩家通过战斗获取资源、收集和培养武将，并在固定防守点位部署阵容，抵御不断推进的敌军。

## 项目特点

- **数据驱动武将**：武将信息存放在 JSON 配置中，方便持续扩充武将目录。
- **武将收集与养成**：支持抽卡获取武将副本，以及同名、同等级副本合成升级。
- **固定点位塔防**：武将自动攻击进入射程的敌人，玩家可以在战斗中切换防守阵容。
- **战斗资源循环**：击败敌人获取金币，用于购买不同等级的武将卡池。
- **单机原型**：当前以本地运行和核心玩法验证为目标，不依赖在线服务。

## 技术栈

- Unity 2022.3 LTS
- C#
- uGUI
- JSON 武将配置

## 项目状态

项目目前处于可玩原型开发阶段，已包含基础 Unity 项目结构、武将数据、抽卡与养成服务，以及第一版波次塔防战斗逻辑。战斗表现仍使用占位图形；本地存档、正式美术和更多玩法仍在开发中。项目尚需在 Unity Editor 中完成实际编译和运行验证。

## 当前阶段

仓库已补齐 Unity 项目基础结构，包括 Packages 清单、Unity 版本、主场景、运行时启动脚本、50 名武将数据和设计文档。主场景会从 JSON 读取武将目录并生成基础原型 UI，可试用抽卡（单抽/十连）、选中武将、合成和固定点位部署。

### 本地运行

1. 安装 Unity Hub，并安装 Unity 2022.3 LTS（项目版本见 ProjectSettings/ProjectVersion.txt）。
2. 克隆仓库，在 Unity Hub 中选择 **Add project from disk**，指向仓库根目录。
3. 等待 Unity 导入资源和编译脚本。
4. 打开 Assets/Scenes/Main.unity，点击 Play。
5. 如果需要把武将数据变成可在 Inspector 中编辑的资源，执行菜单 **Sanguo → Import Hero Catalog**。

当前已实现：固定路径敌人行军、按"最接近基地"优先的自动索敌、满点位循环换将、5 波次战斗、击杀与通关金币奖励、暂停/继续、本地 JSON 存档（版本迁移 + 原子写入，启动时自动恢复）。数值集中在 `BattleTuning` 中统一配置。正式美术、音效与更深的养成线仍在后续开发范围。建议在 Unity Editor 中实际构建验证。

建议使用 Unity 2022.3 LTS 或更新的 LTS 版本。
