# 三国烽火 · Sanguo Tower Defense

《三国烽火》是一款基于 Unity 开发的三国题材单机塔防游戏。玩家通过战斗获取资源、收集和培养武将，并在固定防守点位部署阵容，抵御不断推进的敌军。

## 项目特点

- **数据驱动武将**：武将信息存放在 JSON 配置中，方便持续扩充武将目录。
- **武将收集与养成**：支持抽卡获取武将副本，以及同名、同等级副本合成升级。
- **固定点位塔防**：武将自动攻击进入射程的敌人，玩家可以在战斗中切换防守阵容。
- **战斗资源循环**：击败敌人获取金币，用于购买不同等级的武将卡池。
- **单机原型**：当前以本地运行和核心玩法验证为目标，不依赖在线服务。

## 技术栈

- Unity 2022.3 LTS
- C#
- uGUI
- JSON 武将配置

## 项目状态

项目目前处于可玩原型开发阶段，已包含基础 Unity 项目结构、武将数据、抽卡与养成服务，以及第一版波次塔防战斗逻辑。战斗表现仍使用占位图形；本地存档、正式美术和更多玩法仍在开发中。项目尚需在 Unity Editor 中完成实际编译和运行验证。
