# 开发路线图

## 阶段 1：完整项目骨架

- [x] 建立 Unity 项目目录与包清单
- [x] 记录玩法设计、架构与开发路线
- [x] 建立武将模板、收藏、三档抽卡、合成和布阵服务
- [x] 为武将目录增加初级/中级/高级抽卡等级与三档金币价格
- [x] 提供可扩展武将目录
- [ ] 在 Unity Editor 中验证项目导入和编译

## 阶段 2：可运行战斗原型

- [ ] 敌人路径移动与基地生命（下一步实现）
- [ ] 自动攻击、射程和伤害
- [ ] 波次生成、胜负判定与奖励
- [ ] 战斗中点位换将
- [ ] 基础战斗 HUD

## 阶段 3：局外界面

- [ ] 武将收藏列表、搜索和阵营筛选
- [ ] 抽卡界面、软货币和抽卡反馈
- [ ] 合成材料选择与确认界面
- [ ] 固定点位布阵界面
- [ ] 本地 JSON 存档与版本迁移

## 阶段 4：内容与质量

- [ ] 增加武将和关卡数据
- [ ] 技能、阵营羁绊和敌人类型
- [ ] 数值平衡与战斗节奏
- [ ] 音效、特效、动画和授权美术资源
- [ ] 自动化领域逻辑测试与跨平台构建

## 完成标准

一个阶段只有在 Unity Editor 中实际导入、无编译错误并完成对应玩法验证后，才可标记为完成。GitHub 文件已提交不等于已通过 Unity 构建验证。
